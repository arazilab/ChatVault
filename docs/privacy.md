# Privacy

Your chat data stays on this device.

The extension has no backend, account system, analytics, telemetry, advertisements, or remote logging. It reads data from the user's existing authenticated browser session and stores backups in local browser storage. Chat content is not sent to ChatVault servers because there are no such servers.

The extension may access supported platform pages through declared host permissions. Platform frontend interfaces can change. A backup can be incomplete when a service no longer exposes older, deleted, or unavailable content. The UI must show partial results clearly.

Users can delete local backup data from settings. Exported files are controlled by the user and may contain sensitive chat content.
